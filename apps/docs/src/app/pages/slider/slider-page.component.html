Slider

Pick a number, or a range between two numbers, by dragging a thumb along a track. Bound to a signal, with min, max, and step.

ngAtoms v1.0+ ngatoms add slider Alpha Source

value: {{ heroVal() }}

Usage

Add the slider to your project and import it wherever you need it.

$ ngatoms add slider

Then import into your component:

Range

Set mode="range" and bind [(range)] to a [start, end] tuple. The thumbs cannot cross each other.

range: {{ rangeVal()[0] }} – {{ rangeVal()[1] }}

Min, max, and step

[min] and [max] set the bounds. [step] sets the snap increment and accepts decimals.

value: {{ stepVal() }}

Sizes

Three sizes. md is the default.

sm
md
lg

Disabled

Pass [disabled]="true" to prevent interaction.
