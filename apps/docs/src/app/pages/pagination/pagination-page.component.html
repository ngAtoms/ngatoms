Pagination

Page navigation with previous and next controls and a windowed list of pages. Give it the item count and page size; it works out the rest.

ngAtoms v1.0+ ngatoms add pagination Alpha Source

page {{ heroPage() }} of 12

Usage

Add the pagination to your project and import it wherever you need it.

$ ngatoms add pagination

Then import into your component:

Sibling count

[siblingCount] sets how many pages show on each side of the current one. The first and last pages are always visible.

0
1
2

Sizes

Three sizes. md is the default.

sm
md
lg

Disabled

Pass [disabled]="true" while a page is loading.
