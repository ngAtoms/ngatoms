Code Block

Displays source code with a header, a copy button, and optional line numbers. It ships without a highlighter, so it adds no dependency — plug in the one you already use.

ngAtoms v1.0+ ngatoms add code-block Alpha Source

Usage

Add the code block to your project and import it wherever you need it.

$ ngatoms add code-block

Then import into your component:

Syntax highlighting

Pass a [highlighter] function that takes the code and language and returns HTML. This example uses highlight.js, but Prism or Shiki work the same way. Token colors come from the theme of the library you choose.

Line numbers

Set [lineNumbers]="true" to show a gutter. The numbers are not selectable, so they never end up in a copy.

Without header

With no language or filename and [copyable]="false", the header is dropped.
