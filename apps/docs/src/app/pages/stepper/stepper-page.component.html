Stepper

Shows progress through a sequence of steps. Steps before the active one render as complete; make them clickable to let people jump back.

ngAtoms v1.0+ ngatoms add stepper Alpha Source

Usage

Add the stepper to your project and import it wherever you need it.

$ ngatoms add stepper

Then import into your component:

Vertical

Set orientation="vertical" for narrow layouts. A description adds a second line to each step.

Clickable steps

With [clickable]="true" each step becomes a button that activates it. A disabled step cannot be reached.

Error

Flag a step that failed validation with [error]="true".
