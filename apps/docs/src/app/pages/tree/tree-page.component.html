Tree

A hierarchy of items whose branches expand and collapse. Nest nga-tree-item elements to any depth; selection is bound to a signal.

Controlling branches

Each item has an expanded model. Bind it one-way for an initial state, or two-way to drive it from your own code.

From data

For a tree that comes from an API, render the items with a recursive template.

Disabled items

A disabled item cannot be selected and is skipped by keyboard navigation.
