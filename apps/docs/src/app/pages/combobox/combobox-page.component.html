Combobox

A text field with a list of options that narrows as you type. Pick with the mouse or the keyboard; the value is bound to a signal.

ngAtoms v1.0+ ngatoms add combobox Alpha Source

value: {{ heroVal() ?? 'null' }}

Usage

Add the combobox to your project. The CLI also installs overlay, which it depends on.

$ ngatoms add combobox

Then import into your component:

Sizes

Three sizes. md is the default.

Custom filter

By default an option matches when its label contains the typed text, ignoring case. Pass [filter] to change that — here, labels must start with it.

Disabled and invalid

disabled locks the field. invalid applies error styling. A single option can be disabled with disabled: true.

API

@for (group of propGroups; track group.kind + group.target) {

{{ group.kind }} on {{ group.target }}.

}
