Skeleton

A placeholder that holds the shape of content while it loads. Three variants cover most layouts; size them with plain CSS.

ngAtoms v1.0+ ngatoms add skeleton Alpha Source

Usage

Add the skeleton to your project and import it wherever you need it.

$ ngatoms add skeleton

Then import into your component:

Variants

text follows the font size of its container, circle suits avatars, and rect stands in for images and cards.

text
circle
rect

Sizing

Set width and height with a class or inline style. The skeleton never guesses the size of the content it replaces.

Static

Pass [animated]="false" to drop the shimmer. It is also dropped automatically when the user prefers reduced motion.
