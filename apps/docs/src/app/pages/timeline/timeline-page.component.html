Timeline

A vertical list of events in order, each with a marker and a connector to the next. Use it for activity feeds, order tracking, and changelogs.

ngAtoms v1.0+ ngatoms add timeline Alpha Source

  1. Order placed

    Mar 3, 09:12

  2. Shipped

    Mar 4, 16:40

    Your package left the warehouse and is on its way.

  3. Delivered

    Expected Mar 6

Usage

Add the timeline to your project and import it wherever you need it.

$ ngatoms add timeline

Then import into your component:

Status

Each item takes a status: complete fills the marker and its connector, active rings the marker, and default leaves it hollow.

  1. complete

  2. active

  3. default

Custom markers

An empty marker renders a dot. Put an icon inside it to replace the dot.
