File Upload

A drop zone over a native file input. Drag files in or click to browse; files that break the type, size, or count rules are reported instead of added.

ngAtoms v1.0+ ngatoms add file-upload Alpha Source

Usage

Add the file upload to your project and import it wherever you need it.

$ ngatoms add file-upload

Then import into your component:

Multiple files and validation

multiple appends to the selection. accept uses the native syntax, maxSize is in bytes, and maxFiles caps the list. Anything turned away is emitted through (rejected) with a reason.
