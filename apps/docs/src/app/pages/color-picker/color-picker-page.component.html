Color Picker

Pick a color from a saturation and brightness area, a hue slider, a hex field, or preset swatches. The value is a hex string bound to a signal.

ngAtoms v1.0+ ngatoms add color-picker Alpha Source

value: {{ heroVal() }}

Usage

Add the color picker to your project and import it wherever you need it.

$ ngatoms add color-picker

Then import into your component:

Swatches

Pass [swatches] to offer preset colors below the picker.

Inside a popover

The picker renders inline. To open it from a button, place it inside a popover.

Disabled

Pass [disabled]="true" to prevent interaction.
