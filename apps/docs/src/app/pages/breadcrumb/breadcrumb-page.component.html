Breadcrumb

Shows where the current page sits in the hierarchy and links back up it. Built from plain directives on your own nav, ol, and a elements.

ngAtoms v1.0+ ngatoms add breadcrumb Alpha Source

Usage

Add the breadcrumb to your project and import it wherever you need it.

$ ngatoms add breadcrumb

Then import into your component:

Custom separator

An empty separator renders a slash. Put anything inside it — an icon, a character — to replace it.
