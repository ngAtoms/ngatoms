Tag Input

A text field that turns what you type into removable tags. Press Enter or a comma to add one, Backspace to remove the last.

ngAtoms v1.0+ ngatoms add tag-input Alpha Source

{{ heroTags().length }} tags

Usage

Add the tag input to your project and import it wherever you need it.

$ ngatoms add tag-input

Then import into your component:

Max and duplicates

[max] caps the number of tags. Duplicates are rejected, ignoring case, unless you set [allowDuplicates]="true". Rejected text stays in the field so it can be fixed.

{{ maxTags().length }} / 3

Separators and paste

Besides Enter, any character in [separators] commits a tag. Pasted text is split on those separators and on line breaks.

Sizes

Three sizes. md is the default.

Disabled and invalid

disabled locks the field and its tags. invalid applies error styling.
